# Regression Project

## Objective
Build a simple regression model, make predictions, and evaluate its performance using MAE and MSE.

## Project Structure

- `src/data.py`: Data splitting and validation.
- `src/model.py`: Model creation and training.
- `src/evaluation.py`: Model evaluation using MAE and MSE.
- `src/main.py`: Runs the complete pipeline.
- `tests/`: Contains unit tests.
